# homebrew-tap

Homebrew formulae for [marshallku](https://github.com/marshallku) projects.

## Install

```sh
brew install marshallku/tap/<formula>
```

## Available formulae

| Formula | Description |
| --- | --- |
| [`mac-smart-fans`](./Formula/mac-smart-fans.rb) | Temperature-driven fan control for Apple Silicon Macs ([repo](https://github.com/marshallku/mac-smart-fans)) |
